## Sources deliberately NOT used

- No building-footprint, PUK/SURVEY or municipal building registry dataset — Feature 3 has no Building_ID by design.
- No NASA POWER / PVGIS / NREL bulk download — solar generation values come from Feature 1; bulk irradiance datasets are unnecessary for this feature.
- No admin-boundary shapefile — locality grouping uses the `Locality` column already present in the Feature 1 output; no locality is invented.
- No electricity-tariff dataset — cost and savings are Feature 1 outputs.

## Integrity rules

1. The uploaded Excel is the **only** measurement-bearing input to Feature 3.
2. Every external value used (emission factor, index weights, budgets, thresholds) is
   labelled **E** and is editable by the user.
3. Every derived value (aggregates, Solar Potential Index, CO₂, scenarios) is labelled **B** or **D** and is computed deterministically — never randomised.
4. Synthetic rows are never presented as real-world measurements: the `SYNTHETIC_DEMO` flag is shown on the dashboard, in the rooftop detail, in the report and in the dataset description.

A machine-readable copy of these entries is seeded into the `data_sources` table and
exposed at `GET /api/meta/data-sources`.
